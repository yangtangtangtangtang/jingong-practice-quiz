# 金工实习背题小程序

这是一个用于金工实习题库复习的离线背题小程序。

我是苏州大学电子信息学院 23 级学生汤旸。做这个项目的初衷很简单：金工实习题目数量比较多，大家临近考试时如果只看 PDF，查题、背题、回顾错题都不太方便。所以我把题库整理成了一个可以直接打开使用的 HTML 小程序，希望能帮助大家更高效地背题、刷题和检查掌握情况。

## 项目功能

这个小程序目前包含两个主要模块：测验模块和背诵模块。

## 测验模块

- 支持判断题、选择题、全部题目三种范围。
- 支持顺序做题和乱序做题。
- 支持输入起始题号和终止题号。
- 在“全部”模式下，范围可以跨越判断题和选择题。
- 支持考试模拟模式：随机抽取 30 道判断题和 70 道选择题，共 100 题进行测验。
- 做题后会提示回答正确或错误，并显示正确答案。
- 支持自动记录错题。
- 支持手动把题目加入错题合集。
- 支持错题重做。
- 在错题重做时，可以手动把题目移出错题合集，方便管理错题。
- 支持清空错题合集。
- 支持极速刷题模式：答对后自动进入下一题，答错时停下来查看答案。
- 支持选择题选项乱序：只会打乱选择题选项，判断题仍保持“对 / 错”顺序。
- 每一道题都会显示练习次数、正确次数和错误次数。
- 错误次数达到 5 次后，会自动进入顽固错题库，方便集中复习。
- 错题记录、练习统计和做题进度会保存在当前浏览器中，关闭后再次打开仍然保留。

## 背诵模块

- 支持判断题、选择题、全部题目三种范围。
- 支持顺序背诵和乱序背诵。
- 支持输入起始题号和终止题号。
- 每次显示一道题，并直接给出唯一正确答案。
- 不需要选择选项，适合快速过题和记忆答案。

## 进度导入导出

新版增加了“导出带进度副本”和“导入进度存档”功能，方便在手机和电脑之间同步使用。

- 点击“导出带进度副本”，会生成一个新的 HTML 文件，里面包含当前做题进度、错题、顽固错题、练习统计和功能开关状态。
- 在另一台设备上打开这个带进度的 HTML 文件，就可以继续使用。
- 也可以点击“导入进度存档”，选择之前导出的 HTML 文件，把进度导入到当前页面。

需要注意的是，进度本质上仍然保存在浏览器本地。如果换手机、换电脑、换浏览器，建议先导出带进度副本，再在新设备上导入。

## 电脑上怎么用

1. 下载项目里的 HTML 文件。
2. 找到最新版文件，例如 `金工实习背题小程序V5.0.html` 或仓库中标注为最新版的 HTML 文件。
3. 双击打开，或右键选择用 Chrome、Edge 等浏览器打开。
4. 打开后即可使用，不需要安装软件，也不需要联网。

建议使用 Chrome 或 Edge 浏览器，兼容性会更好。

## 手机上怎么用

1. 把 HTML 文件发送到手机上，例如通过微信文件传输助手、QQ、网盘、数据线等方式。
2. 在手机文件管理器中找到这个 HTML 文件。
3. 选择用浏览器打开。
4. 打开后即可在手机上使用。

如果手机默认打开方式不是浏览器，可以长按文件，选择“用其他应用打开”，再选择浏览器。

如果在微信或 QQ 内置预览里打开出现异常，建议把文件保存到手机本地，再用系统浏览器、Chrome、Edge、Safari 等浏览器打开。

## 手机和电脑之间怎么同步

如果想把电脑上的进度同步到手机：

1. 在电脑上打开小程序。
2. 点击“导出带进度副本”。
3. 把导出的 HTML 文件发送到手机。
4. 在手机上用浏览器打开这个新文件。

如果想把手机上的进度同步到电脑：

1. 在手机上打开小程序。
2. 点击“导出带进度副本”。
3. 把导出的 HTML 文件发送到电脑。
4. 在电脑浏览器中打开，或者在电脑页面中点击“导入进度存档”导入。

## 使用建议

- 如果想模拟做题，可以进入“测验模块”。
- 如果想按考试节奏练习，可以使用“考试模拟模式”。
- 如果想快速背答案，可以进入“背诵模块”。
- 如果只想复习某一段题目，可以设置起始题号和终止题号。
- 如果想提高刷题速度，可以打开“极速刷题模式”。
- 如果担心只记住选项位置，可以打开“选择题选项乱序”。
- 如果某道题总是记不住，可以手动加入错题合集，后面集中复习。
- 如果某道题错了很多次，可以去顽固错题库里专门复习。
- 如果要换设备使用，记得先导出带进度副本。
